**A work-in-progress platform for experimenting with open-source creative tools in real time.**

SoundSink provides a no-code interface for interacting with Hydra, Babylon.js, ChucK, and other open-source tools.

**Try it live:** [Portfolio Demo](https://portfolio-git-main-matthew-reillys-projects.vercel.app) – click the **Hydra** button to start experimenting.

**Core ideas:**
- Real-time audio and video processing
- No-code interaction with Hydra, Babylon.js, and ChucK
- Modular, open-source tool networking for easy experimentation

**Current Features:**
- MIDI-friendly ChucK editor for procedural audio (sequencer, effects, triggers, sampling -- nearly complete)
  
**Planned extensions:**
- RAG-style AI assistant to suggest and automate workflows
- Expanded tools for building interactive, research-friendly interfaces
