# SoundSink

## Demo

https://github.com/user-attachments/assets/f9079fc3-0122-4f2e-bdb0-1c8919b51f99

This is a work-in-progress demo exploring the integration of open-source creative coding tools for expressive, real-time audiovisual experimentation.

**Try it live:** [Portfolio Demo](https://portfolio-git-main-matthew-reillys-projects.vercel.app) – click the **Hydra** button to edit video (or live camera input) projected inside a Babylon.js 3D sphere. The UI exposes Hydra operations through a no-code interface, letting users manipulate visuals in real time.

**Core ideas:**
- Real-time audio and video processing
- No-code interaction with Hydra, Babylon.js, and ChucK
- Open-source tool networking for easy experimentation

**Planned extensions:**
- MIDI-friendly ChucK editor for procedural audio
- RAG-style AI assistant for workflow automation
- Expanded tools for building interactive, research-friendly interfaces
