# Portfolio

This repository is a work-in-progress and a working demo of a fun experiment integrating my favorite open source technologies. Visit 
https://portfolio-git-main-matthew-reillys-projects.vercel.app, click the Hydra button, and try editing the video (or camera stream) projected inside of Babylon.js 3d. Engage with the underlying logic and functionality of Hydra using a no-code GUI. Check back soon for updates to the midi-friendly ChucK editor, RAG helper for audio-video experimentation, and extended options for building 3D and IoT UI with Babylon.
