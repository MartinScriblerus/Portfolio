This repository is a work-in-progress demo exploring the integration of several open-source creative coding tools.

Visit https://portfolio-git-main-matthew-reillys-projects.vercel.app, click the **Hydra** button, and experiment with editing video (or a live camera stream) projected inside a Babylon.js 3D scene. The UI exposes Hydra’s underlying logic through a no-code interface, allowing users to interact with and manipulate visuals in real time.

Planned extensions include a MIDI-friendly ChucK editor, a RAG-based helper for audio-video experimentation, and expanded tooling for building 3D and IoT interfaces with Babylon.js.
